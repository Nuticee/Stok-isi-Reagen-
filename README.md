# Stok Reagen

Aplikasi stok reagen berbasis web/PWA.

Fitur:
- Scan barcode dengan metode scanner yang sudah diuji
- Barcode tidak harus berada di tengah foto
- Mapping GTIN/barcode ke nama reagen
- LOT dan Expired GS1 otomatis
- Pembukaan reagen
- Pemakaian reagen
- Stok otomatis
- Riwayat
- Edit dan hapus data
- Export CSV
- Backup JSON
- Penyimpanan lokal browser

Untuk GitHub Pages:
1. Upload semua file di folder ini ke root repository.
2. Aktifkan Settings → Pages.
3. Pilih Deploy from a branch → main → /(root).
4. Buka URL GitHub Pages yang diberikan.
5. Tambahkan ke layar utama HP bila diinginkan.

Catatan:
Data aplikasi disimpan lokal pada browser/perangkat yang digunakan. GitHub Pages hanya menyajikan file aplikasinya.
